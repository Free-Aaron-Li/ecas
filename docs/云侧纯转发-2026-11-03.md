> 先生令：「所有流量只能通过云服务器传输，且云服务器不负责数据库、运算等工作，只负责流量转发，隐藏本地服务器。」

- `journalctl -u sshd` 显示同一时刻 `Accepted publickey for root from 171.219.114.164 / 171.219.115.152`，
  指纹 `SHA256:2DznbNarIE9YlfA2OFAP6hyUzytSSB0hwIeDq7tloj0`（ED25519，oranpear@icloud.com）＝先生本机密钥。

- 判为异常只因**同一个人的出口 IP/运营商在几分钟内跳变**（电信/移动双线）。时间窗 15:47–18:11 正是改 RTU 透传的工作时段。
- 无后门：uid0 仅 root、`authorized_keys` 1 行且 mtime 2026-09-25、cron 仅腾讯云自带、无异常 timer、宝塔 login.log 为空。

## 2. 改造后架构

```
DTU 4G(180.108.106.x) ──8883──▶ 腾讯云 124.222.122.146
                                  └ iptables DNAT → 10.10.10.11:8883 (EasyTier tun0)
                                        └ 本地 ecas-rtu-master (Modbus 主站, 1Hz)
                                              └ MQTT QoS1 → 127.0.0.1:1883 (ecas-mosquitto)
                                                    └ collector ──▶ Postgres raw_reading (本地)
```

- 云侧只保留：sshd(22)、EasyTier(11010/11011/15888/43421 + 12121 管理台)、**纯 iptables 转发**。
- 云端 mosquitto 与 `rtu_master.py` 已下线（mosquitto `masked`，永不回启）。
- 白名单与安全组、nft(`ecas_relay`) 一致：仅 **180.108.106.0/24**（现场 DTU）。
