# FMC400 电磁流量计 · 现场接入作业单

> 目标：**把流量计（站号 8）并到现役 485 总线上，由同一台塔石 DTU 轮询，经 MQTT 与浓度计一起上报。**
> 浓度计那一路（站号 1 / FC04）不受影响，全程不必停。
> 编制：2026-11-02　｜　设备：FMC400 电磁流量计（手册 C-004CMF-CN1，见 `~/Documents/参考/产品说明书/流量计/`）
> 相关：`docs/设备资料/FMC400-电磁流量计-速查.md`、`docs/485仪表接入SOP.md`

## 0. 物料与前置

| 项 | 规格 / 要求 |
|---|---|
| 线材 | 屏蔽双绞线 RVSP 2×0.75（现场随货线同规格也可），长度按实际 +1 m 余量 |

| 并线端子 | 模块 A/B 端子若只能进一根线，用并线端子或双线压接钳，**禁止缠绕 + 胶布** |
| 接地线 | 流量计**单独**一根到接地排（见 3.2，手册硬要求） |
| 工具 | 万用表（通断 / 电阻 / 直流电压）、螺丝刀、USB-485 转换器 + 笔记本（配 DTU 用） |
| 前置 | ⚠️ **接口机/笔记本上的中盛软件、Modbus Poll 必须全部关闭并拔掉 USB-485**（DTU 与它们是双主站，会抢总线） |

## 1. 拓扑（一主两从，一条总线）

```
  TAS-KS-301(DTU/主站) ──A/B── 中盛AI模块(站1, FC04) ──A/B── FMC400(站8, FC03)
                                     ↑ 从模块端子上并出这一对
```

## 2. 接线（断电做）

| 步骤 | 动作 |
|---|---|
| 2.1 | 停 DTU 电源（流量计不断电，从站悬空不影响计量） |
| 2.2 | 流量计端子认清：`TX+` = 485+、`TX−` = 485−（手册表 5，**不是** A/B 丝印） |
| 2.3 | `TX+` → 总线 **A**、`TX−` → 总线 **B**；线的两端都套 `A8` / `B8` |
| 2.4 | 另一端从**中盛 AI 模块的 A/B 端子**并出（手拉手），不从 DTU 拉两根长线分叉成星型 |
| 2.5 | 屏蔽层：新段接老段屏蔽/柜内接地排，**流量计端悬空** |
| 2.6 | 走线：沿桥架/穿管，与动力线平行 ≥30 cm，交叉走 90°，避开变频器输出线 |

## 3. 两个硬要求（手册原文，别省）

1. **单独接地**：传感器与外壳/转换器保护接地之间不允许有电位差，**必须单独接地，不得与其它电气设备共用**（共用会产生漏电流 → 串模干扰，严重时无法工作）。**不要把流量计接地线并在浓度计/AI 模块的接地螺钉上。**
2. **直管段**：前 ≥10DN、后 ≥5DN（DN150 → 1.5 m / 0.75 m），必须满管、无气穴。

## 4. 上电前测量（万用表，断电状态）

| 测点 | 正常 | 异常处理 |
|---|---|---|
| A–B 之间电阻 | 120 Ω（单端终端）或 60 Ω（两端各 120 Ω） | ≈0 Ω = 短路；∞ = 断线/没接上 |
| A/B 对地（外壳） | 不通（MΩ 级） | 通 = 线破皮 / 接到 24V 上了 |

> 终端电阻只加**物理两端**（DTU 侧 + 最远设备），中间节点不加。

## 5. DTU 配置（PC 走 USB-485 接总线）

```
+++                                      ← 进 AT 模式（+AUTOATO: 120，120 秒无动作自动退出）
AT+POLLSTR=2,1,0,"08030000000EC497"      ← 槽 2：站号8 读 0~13（流速/瞬时/百分比/累积32位/报警/流向）
AT+ALL?                                  ← 回读：应看到 +POLLSTR2: 1,0,"08030000000EC497"
AT&W                                     ← 保存
AT+CFUN=1,1                              ← 重启生效（回显 AT soft restart!）
```

- **不要动槽 1**（`01040000000131CA`，浓度计），它一改浓度就断采。
- **配置完立即拔掉 USB-485**（DTU 重启后开始轮询，PC 若还并着就是两个主站打架）。
- 退一步的备选指令（DTU 对 37 字节长帧支持不好时）：
  - 只读 0~9（29 B 帧）：`08030000000AC554`
  - 拆两条各读 5 个：`0803000000058550` + `0803000500059551`
- 若还想拿「总累积 / 流量单位」（浮点块）：加槽 3 `AT+POLLSTR=3,1,0,"0803005A0012E54D"`

## 6. 现场即时判据

| 看什么 | 应该看到 |
|---|---|
| DTU 485 TX/RX 灯 | **两种节奏交替**（模块 fc04 与流量计 fc03） |
| 流量计显示 | 瞬时 ~211 m³/h、累积 5181 m³（与出厂现场一致就说明没接错） |
| 上电后 A–B 电压 | 0.2~1 V 左右；0 V ⇒ 先对调 A/B 再查线 |

## 7. 服务器验收（回办公室做，5 分钟）

```bash
ssh ecas
/root/ecas/scripts/capture-run.sh --duration 300        # 原始帧自动落 /root/ecas/capture/<时间戳>-dpro66.jsonl
```

**判据（工具自动判定，退出码 0 = 通过）**

| 项 | 期望 |
|---|---|
| 浓度帧 | 站 1 / FC04 / **11 B**，浓度约 50~56 % |
| 流量帧 | 站 8 / FC03 / **37 B**（读到 0~13），流量 ≈211 m³/h、流速 ≈3.319 m/s |
| 间隔 | 两站各自 100 s 上下（DTU 上报节流的既定节奏），**交替**出现 |
| 输出 | `✅ 判定：硬件采集通过（两站都在、帧可解）` |

工具会把「读到几个寄存器」反推成帧长，所以**能直接看出 DTU 里配的是哪条指令**（29 B = 旧方案 0~9；37 B = 推荐 0~13；45 B = 浮点块 90~107）。

## 8. 失败对照表（工具报错 → 现场原因）

| 现象 | 原因与处置 |
|---|---|
| 没有流量帧 | ①槽 2 没下发/没 `AT&W`/没重启 ②站号不是 8 ③`TX±` 接反或没接 ④波特率/校验位不一致（应 9600 8N1） |
| 流量读到 0 | 空管/未满管，或配的指令读了保留寄存器（确认是 `08030000000EC497`） |
| 帧里有 `0x83` 异常应答 | 「非法的数据值」——DTU 把读写混了/起始地址越界，回读 `AT+ALL?` 核槽 2 字符串 |
| 帧长不符 / 只有半帧 | DTU 对 37 B 长帧转发不完整 ⇒ 退化为 0~9（29 B）或拆两条 5 寄存器 |
| 浓度帧也没了 | 槽 1 被覆盖 ⇒ 立即回写 `01040000000131CA`（`AT+ALL?` 确认） |
| 两站都在但间隔 > 300 s | 上报节流（`DTUPACKET`）问题，与接线无关，按 SOP 1130 行那节继续查 |

## 9. 回退（现场出问题就回到已知good状态）

1. 槽 2 清空：`+++` → `AT+POLLSTR=2,0,0,""` → `AT&W` → `AT+CFUN=1,1`
2. 拆掉新增的一对 `A8/B8`（不影响浓度链路）
3. 服务器侧确认浓度帧恢复
