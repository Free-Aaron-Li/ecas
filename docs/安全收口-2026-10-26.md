# ECAS 访问面收口记录 · 2026-10-26

> **先生令（2026-10-26）**：「对浓度采集网站安全性进行更改，仅允许我这台电脑访问，其他一律禁止。」
> 结论：**除「先生这台 Mac 经 SSH 隧道」以外，所有入口全部关闭**（不是白名单，是关死）。

## 1. 决策与理由

| 议题 | 选择 | 为什么 |
| --- | --- | --- |
| 谁可以访问 | **只有先生这台 Mac** | 先生原话「其他一律禁止」 |
| 怎么识别「这台 Mac」 | **SSH 私钥**（本机 → ubuntu-super 的隧道） | 本机公网出口实测 `219.77.163.203`，经 Clash 代理，**动态且共享**；IP 白名单会连带放行同出口用户、且 IP 一变自锁 |
| 后端绑哪 | **`127.0.0.1:18080`** | 回环 + 隧道＝唯一入口；叠加网/公网/VPC 全部够不着 |
| 公网域名/IP/VPC | **全关** | 先生：「确认，全部关死」 |

## 3. 执行步骤（可重放）

```bash
# ① 目标机改绑（幂等；内部会先备份 .env 再重建 api，并验证 mesh 地址已拒连）
PW=$(python3 -c 'import tomllib;print(tomllib.load(open("/Volumes/keys/ssh/ssh.toml","rb"))["ubuntu_Super_Server"])')
{ printf '%s\n' "$PW"; cat web/deploy/ubuntu/lockdown-rebind.sh; } | ssh ubuntu-super "sudo -S -p '' bash -s"

# ② 本机隧道（仓库副本 → ~/Library/LaunchAgents → bootstrap）
cp web/deploy/com.ecas.tunnel.plist ~/Library/LaunchAgents/
launchctl bootout  gui/$(id -u)/com.ecas.tunnel 2>/dev/null || true
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.ecas.tunnel.plist

# ③ 公网域名换 403 桩
bash ~/.files/dsh/bin/cred-keychain.sh run cf-api-token -- bash -c \
  'cd ~/.files/dsh/ecas-gateway && CLOUDFLARE_API_TOKEN="$CRED_VALUE" npx --yes wrangler@4 deploy'

# ④ 停 VPC 隧道 与 腾讯云边缘
ssh ubuntu-super 'docker update --restart=no cloudflared && docker stop cloudflared'
ssh ecas 'cd /opt/ecas-edge && docker compose stop && docker update --restart=no ecas-edge'
```

## 6. 遗留与注意

1. **隧道依赖 easytier 叠加网**：mesh 断了 → 隧道连不上 → 看板不可达（`com.user.ecas-health-watch` 会播报）。
2. **腾讯云安全组 80/443 规则仍在**：容器停了 ⇒ 无监听 ⇒ 不可达；要真正删规则需先生控制台操作
   （本机不持有腾讯云密钥，且 `tighten-security-group.py` 需临时密钥）。
3. **账号数据未动**：`web_account`（`xsh` / `viewer`）保留；恢复域名后原登录方式即恢复。
   弃用期可考虑停用 `viewer`（最后登录 2026-10-25 16:46）。
4. **重新部署**：`deploy.sh all` 会用仓库里已同步的 `BIND_IP=127.0.0.1` 重写 `/opt/ecas/.env`，不会重新开门；
   若手工改过服务器 `.env`，重部署前先确认。
5. **前端 dist 更新**不需要重开隧道（隧道只在 TCP 层转发）。
