## 一、通讯口径（手册 4.3 / 6.3 / 附录 C）

| 项 | 值 | 与现场/DTU 对照 |
|---|---|---|
| 接口 | RS485（端子 **`TX+` = 485+**、**`TX−` = 485−**） | 现场按 TX+/TX− 接线，**不是** A/B 丝印 |
| 协议 | Modbus-RTU，功能码 `03` 读 / `10` 写 | DTU 轮询用 `03` |
| 字格式 | **10 位 = 1 起始 + 8 数据 + 无校验 + 1 停止（8N1）** | ✅ 现场 9600 8N1 |
| 从站地址 | **01~99**（0 保留） | ✅ 现场设 8，不与浓度链路（1）冲突 |
| 波特率 | 1200/2400/4800/9600/19200 | ✅ 9600 |
| 单次最多读 | **50 个寄存器** | 现方案读 14 个 |
| 时序 | 帧间静止 >50 ms；主机超时 >200 ms | DTU 轮询 1000 ms 足够 |
| CRC | 16 位，**低字节在前** | 手册三处示例与本地算法逐条对齐 |

## 三、现场实测值与寄存器表核对（2026-11-02 截图，站号 8 读取 0~9）

| 地址 | 实测值 | 按手册解读 | 校验 |
|---|---|---|---|
| 0/1 | 0 / 3319 | 流速 = 3319÷1000 = **3.319 m/s** | 原「含义未知」已解 |
| 2/3 | 0 / 21116 | 瞬时流量 = 21116÷100 = **211.16 m³/h** | ✅ 与先生口径一致 |
| 4 | 6598 | 流量百分比 = **65.98 %** | 反推量程 ≈ 211.16÷0.6598 ≈ **320 m³/h** |
| 5 | 0 | 空管百分比 0 % | 空管正常 |
| 6/7 | 0 / 5181 | 正向累积 = **5181 m³** | ✅ 与先生口径一致 |
| 8/9 | 0 / 0 | 反向累积 0 | 无倒流 |

**三重自洽**：流速 3.319 m/s × 截面积 → 211.16 m³/h（反算管径 **D ≈ 150 mm**）；211.16 ÷ 320 ≈ 65.9 % 与 addr4 相符。三条路径互相验证，说明该手册与本台表一致。

⚠️ **累积量必须成对读取**：满量程 ~320 m³/h 时，16 位（65535）**约 8.5 天就会回绕**。只读 addr7（低 16 位）会在 8 天后把累积值读成 0；必须 addr6 高字 + addr7 低字拼成 32 位。

## 四、DTU 轮询指令（站号 8，CRC 已按手册示例验证）

| 用途 | RTU 指令 | 应答数据域 | DTU 转出的 TCP 帧长 |
|---|---|---|---|
| **推荐**：读 0~13（流速/瞬时/百分比/空管/正累积/反累积/报警/流向） | `08 03 00 00 00 0E C4 97` | 28 B | **37 B** |
| 读 0~9（原方案，够看瞬时+累积低字） | `08 03 00 00 00 0A C5 54` | 20 B | 29 B |
| 读 90~107（手册常用块：浮点累积/流量/单位/报警） | `08 03 00 5A 00 12 E5 4D` | 36 B | 45 B |
| 读 90~95（正/反/总累积，浮点） | `08 03 00 5A 00 06 E5 42` | 12 B | 21 B |
| 读 98~99（瞬时流量，浮点） | `08 03 00 62 00 02 65 4C` | 4 B | 13 B |
| 读 21~23（管径 + 量程） | `08 03 00 15 00 03 14 96` | 6 B | 15 B |

塔石 DTU 下发：`AT+POLLSTR=2,1,0,"08030000000EC497"` → `AT&W` → `AT+CFUN=1,1`。

## 五、现场接线要点（手册 4.2~4.5 强化版）

1. **端子**：`TX+` → 总线 A（485+），`TX−` → 总线 B（485−）；按丝印接，不通再对调一次。
2. **接地（比一般仪表严格）**：手册危险提示——传感器与外壳/转换器保护接地之间**不允许存在电位差**，必须**单独接地**，**不得与其它电气设备共用接地**（共用会产生漏电流干扰，严重时无法工作）。→ 流量计接地线单独走一根到接地排，不要图省事并在浓度计/AI 模块的接地螺钉上。
3. **屏蔽层**：单端接地，接在 DTU 侧柜内接地排；流量计端悬空。
4. **电源**：85~264 VAC 或 18~28 VDC，功耗 ≤8 W；L/N 或 24V+/24V− 按铭牌确认。
5. **安装复核**：前直管段 ≥10DN、后直管段 ≥5DN（DN150 → 1.5 m / 0.75 m），必须满管、无气穴。
6. 4~20 mA（`IOUT`/`ICOM`，无源用 `IVee`）本项目暂不走——MODBUS 已给全量数据。

## 六、采集端注意（配合现有 `dpro66_monitor.sh`）

- 现脚本按 **11 字节定长 + fc=04** 认浓度帧；流量计是 **fc=03**、帧长随 LEN 变化（推荐方案 37 B）⇒ 需按 LEN 动态切帧、按站号分流。
- 32 位拼接：`瞬时 = addr2<<16 | addr3`；`正累积 = addr6<<16 | addr7`；缩放 `÷100`、`÷1`。
- **只读**：严禁向 96/97（累积清零）或任何 21~60 的 RW 配置寄存器写入。
